# 3.2.1. 학계 동향

**최근 ECG 분석 연구는 단일 질환을 예측하는 개별 모델 중심에서 벗어나, 다양한 ECG 관련 과제에 활용할 수 있는 ECG Foundation Model 중심으로 빠르게 전환되고 있습니다.** 기존 연구는 주로 CNN, ResNet, Transformer 등을 이용해 부정맥, 심근경색, 전도장애와 같은 특정 진단 과제를 수행하는 방식이 많았습니다. 그러나 최근에는 대규모 ECG 데이터를 사전학습하여 적은 라벨만으로도 여러 질환 진단, 위험도 예측, 환자 상태 추정에 활용할 수 있는 범용 표현 학습 모델이 활발히 제안되고 있습니다. ECG-FM은 150만 개 규모의 ECG 데이터를 활용해 hybrid self-supervised learning 기반의 공개 ECG foundation model을 제안하였으며, ECGFounder는 1,000만 개 이상의 임상 ECG와 150개 진단 라벨을 기반으로 대규모 ECG foundation model을 구축하였습니다.

**학습 방법 측면에서는 단순히 ECG를 일반 시계열로 처리하는 방식에서 벗어나, ECG 신호의 의학적 특성을 반영하려는 흐름이 강해지고 있습니다.** HeartLang은 심장 박동을 “단어”, 리듬을 “문장”처럼 해석하여 ECG의 형태적 특징과 리듬 특징을 함께 학습하는 ECG language processing 관점을 제안하였습니다. CREMA는 masked autoencoder 기반의 생성 학습과 contrastive learning을 결합하여 ECG의 국소 파형 특징과 전체 리듬 패턴을 동시에 학습하도록 설계되었습니다. HuBERT-ECG 역시 음성 분야의 HuBERT 구조를 ECG에 적용하여, ECG segment의 잠재 구조를 군집화하고 masked modeling으로 학습하는 방식의 대규모 self-supervised foundation model을 제안하였습니다.

**또 다른 중요한 흐름은 ECG 신호만 사용하는 것을 넘어, 임상 지식과 다른 정보원을 함께 활용하는 방향입니다.** KED는 ECG signal, ECG report, label text를 함께 정렬하는 signal-language 구조를 통해 zero-shot ECG 진단 가능성을 제시하였으며, 특히 학습 중 보지 못한 질환이나 외부 병원 데이터에서도 진단 가능성을 평가하였습니다. TolerantECG는 ECG 신호와 지식 기반 텍스트 리포트를 함께 활용하면서, 노이즈가 있거나 일부 lead가 없는 불완전한 ECG에서도 안정적인 표현을 학습하도록 설계되었습니다. CLEF는 임상 위험 점수와 메타데이터를 contrastive learning에 반영하여, wearable 기기와 원격 모니터링에서 중요한 single-lead ECG 분석 성능을 높이는 방향을 제안하였습니다.

**응용 분야도 기존의 부정맥 탐지나 파형 이상 분류에서 점차 확장되고 있습니다.** 최근 연구들은 ECG를 단순한 심장 리듬 기록이 아니라, 심혈관 질환의 구조적 이상, 좌심실 기능 저하, 심부전, 관상동맥질환, 사망 위험, 향후 심혈관 사건까지 예측할 수 있는 생체 신호로 보고 있습니다. 예를 들어 ECGFounder는 나이, 성별, CKD, CHD, LVEF, NT-proBNP, PPG 기반 AF detection 등 다양한 downstream task를 평가하였으며, HuBERT-ECG는 164개 심혈관 상태와 미래 사망 사건 예측까지 포함하는 폭넓은 평가를 수행하였습니다.

종합하면, 최근 ECG 학계 동향은 대규모 사전학습, ECG 특화 표현 학습, 임상 지식 결합, 불완전한 실제 ECG 환경 대응, 평가 기준의 임상적 확장으로 요약할 수 있습니다. 이는 ECG 기반 AI가 단순한 자동 분류 모델을 넘어, 다양한 임상 환경에서 활용 가능한 범용 진단·예측 도구로 발전하고 있음을 보여줍니다. 다만 실제 의료 현장 적용을 위해서는 병원 간 데이터 분포 차이, 라벨 불균형, single-lead 및 missing-lead 환경, 모델 해석 가능성, 외부 검증과 재현성 문제를 함께 해결하는 방향으로 연구가 계속 진행될 필요가 있습니다.
