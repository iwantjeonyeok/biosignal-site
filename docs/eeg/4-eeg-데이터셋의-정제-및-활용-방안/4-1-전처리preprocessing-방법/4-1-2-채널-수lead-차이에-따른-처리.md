# 4.1.2 채널 수(Lead) 차이에 따른 처리

## 왜 필요한가

EEG 데이터셋마다 사용된 전극의 수와 위치가 다릅니다. DEAP는 32채널, PhysioNet Motor Imagery는 64채널, TUEG는 19~23채널, 일부 임상 데이터는 10-20 시스템 기반 19채널을 사용합니다. 채널 수가 다른 데이터를 그대로 단일 모델에 입력하면 입력 차원이 달라 배치 처리가 불가능합니다. 또한 특정 데이터셋에서는 일부 전극 위치에 대한 기록이 없는 경우도 있습니다. 이를 처리하지 않으면 다중 데이터셋 통합 학습이나 피험자 간 일반화가 어렵습니다.

## 주요 방법

### 공통 채널 추출 (Common Channel Selection)

여러 데이터셋 간에 공통으로 존재하는 전극만 추출하여 통일된 채널 집합을 구성합니다.

- **방법**: 데이터셋 A가 64채널, 데이터셋 B가 19채널이라면, 19채널 중 두 데이터셋에 공통으로 존재하는 채널들만 선택합니다.
- **장점**: 구현이 단순하고 추가 정보 생성 없이 신뢰할 수 있는 채널만 사용합니다.
- **단점**: 채널 수가 가장 적은 데이터셋 수준으로 정보가 손실됩니다. 특히 고해상도 데이터셋이 가진 공간 정보의 많은 부분을 버리게 됩니다.
- **실무 팁**: 10-20 표준 전극(Fz, Cz, Pz, Oz, F3, F4, C3, C4 등) 기반으로 최소 공통 집합을 정의하면 데이터셋 간 호환성이 높아집니다.

### 채널 보간 (Spatial Interpolation)

존재하지 않는 채널의 신호를 인접 채널의 가중합으로 추정합니다.

- **구면 스플라인 보간(Spherical Spline Interpolation)**: 두피를 구면으로 모델링하고, 두피 위의 전위 분포가 라플라스 방정식을 만족한다는 가정 하에 결측 위치의 전위를 추정합니다. EEG 분석 라이브러리 MNE-Python에서 `raw.interpolate_bads()` 함수로 지원됩니다.[^1]
- **단순 가중 평균**: 주변 채널들의 신호를 거리에 따른 가중치로 평균하는 방식. 구면 스플라인보다 단순하지만 근사치에 가깝습니다.
- **주의사항**: 보간은 실제로 측정하지 않은 신호를 추정하는 것입니다. 보간된 채널이 많을수록 신뢰도가 떨어지며, 특히 서로 멀리 떨어진 채널 간 보간은 오류가 커집니다. 일반적으로 전체 채널의 5~10% 이하에서만 보간을 적용하는 것이 권장됩니다.

### 채널 위치 임베딩 (Channel Position Embedding)

딥러닝 모델, 특히 Transformer 기반 모델에서는 각 채널의 3D 위치 좌표(x, y, z)를 임베딩 벡터로 변환하여 모델에 입력하는 방법을 사용합니다. 이렇게 하면 채널 수가 데이터셋마다 달라도 모델이 채널의 공간적 위치를 기반으로 유연하게 처리할 수 있습니다. EEG Foundation Model들(LaBraM 등)이 이 방식을 채택하여 다양한 채널 구성의 데이터셋을 하나의 모델로 처리합니다.

## 방법 선택 기준

| 상황 | 권장 방법 |
|---|---|
| 다운스트림 태스크가 특정 채널에 집중될 때 (예: Motor Imagery → C3/C4) | 공통 채널 추출 |
| 데이터셋 간 채널 수 차이가 적고 보간 거리가 가까울 때 | 채널 보간 |
| 다양한 채널 수의 데이터셋을 하나의 범용 모델로 처리할 때 | 채널 위치 임베딩 |

## 실무 주의사항

- 채널 이름이 같아도 데이터셋마다 좌표 기준(montage)이 다를 수 있습니다. MNE-Python의 표준 몽타주(`standard_1020`, `standard_1005` 등)를 기준으로 채널 위치를 정규화하는 것이 좋습니다.
- 채널을 선택할 때 레이블(label) 정보를 참고하면 특정 태스크에 관련된 채널을 더 잘 선택할 수 있습니다만, 이는 학습셋에서만 적용해야 하며 테스트 데이터 누수(test leakage)를 방지해야 합니다.
