# 3.1. 과거: 전통적 EEG 해석 방식의 한계와 전환 배경


딥러닝이 EEG 분석에 도입되기 전까지, EEG 연구는 신호처리 기반 특징 추출과 전통적인 기계학습 분류기를 조합하는 방식이 주를 이루었습니다.

## 전통적 분석 파이프라인

전통적 EEG 분석은 크게 세 단계로 구성됩니다.

**1단계 — 전처리**: 전문가가 수동으로 아티팩트(눈 깜빡임, 근전도 등)를 제거하고, 관심 채널을 선택합니다. ICA나 bandpass 필터 등 표준 기법을 사용하지만, 어떤 컴포넌트가 아티팩트인지 판단하는 과정에서 전문가의 주관적 판단이 개입됩니다.

**2단계 — 특징 추출**: 처리된 신호에서 분류에 유용한 수치적 특징을 수동으로 설계합니다.

- **PSD (Power Spectral Density)**: 각 주파수 밴드의 에너지를 계산하여 뇌 상태를 표현
- **CSP (Common Spatial Pattern)**: 두 클래스 간 분산 비율을 최대화하는 공간 필터로, Motor Imagery BCI에서 오랫동안 표준으로 사용됨
- **ERD/ERS 분석**: 사건 전후 특정 주파수 대역의 에너지 변화를 정량화
- **파형 형태 분석**: P300 잠재기, 진폭 등 수동으로 정의된 파형 특성 측정

**3단계 — 분류**: 추출된 특징 벡터를 SVM(Support Vector Machine), LDA(Linear Discriminant Analysis), k-NN 등 전통적 분류기에 입력합니다.

## 전통 방식의 성과와 한계

이 접근법은 명확한 해석력이라는 장점이 있었습니다. 예를 들어 CSP로 추출된 공간 필터가 운동 피질에 집중한다는 것을 직접 확인할 수 있었고, PSD 기반 특징은 신경생리학적 이론과 직결되었습니다.

그러나 다음과 같은 구조적 한계가 있었습니다.

**① 전문가 의존적 전처리**: 아티팩트 판단, 채널 선택, 특징 설계 모두 전문 지식이 필요했습니다. 예를 들어 근전도(EMG) 아티팩트는 Gamma 대역(30 Hz 이상)과 주파수가 겹쳐 자동 분리가 어렵고, ICA 컴포넌트 해석도 숙련된 판단이 요구됩니다. 이는 대규모 데이터 처리를 어렵게 만들었습니다.

**② 수작업 특징 설계의 정보 손실**: CSP는 두 클래스 분리에 최적화되어 있지만, 복잡한 다중 클래스 문제에서는 유용한 정보를 놓칠 수 있습니다. PSD 특징은 시간 정보를 버리는 단점이 있어, 밀리초 단위로 빠르게 변하는 EEG 패턴을 포착하는 데 한계가 있었습니다.

**③ 개인 간 변이(inter-subject variability) 처리 곤란**: 뇌파는 동일한 자극에도 사람마다 다른 패턴을 보입니다. 전통 모델은 한 피험자에서 잘 작동해도 다른 피험자에 그대로 적용하면 성능이 크게 떨어지는 경우가 많았습니다(피험자 의존적 모델).

**④ 소규모 데이터에서의 과최적화**: 특징 추출 후 SVM/LDA에 입력하는 방식은 데이터가 수십 명 수준일 때는 작동하지만, 이 방식으로 설계된 파이프라인을 수백~수천 명의 대규모 데이터로 확장하기 어려웠습니다.

## 전환의 배경

2010년대 이후 대규모 EEG 공개 데이터셋(TUEG, CHB-MIT, SEED 등)이 축적되고, GPU 기반 딥러닝 인프라가 보편화되면서 상황이 바뀌었습니다. 복잡한 EEG 패턴을 데이터로부터 자동으로 학습하는 딥러닝 기반 접근 방식이 전통 방법의 한계를 넘어서기 시작했습니다.[^1]
