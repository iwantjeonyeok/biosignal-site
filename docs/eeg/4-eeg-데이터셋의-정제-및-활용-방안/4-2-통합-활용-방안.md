# 4.2. 통합 활용 방안


전처리를 통해 이질성을 제거한 EEG 데이터는 다양한 방식으로 AI 모델 학습에 통합 활용할 수 있습니다. 어떤 방식을 선택할지는 **보유한 레이블 데이터의 양**, **타깃 태스크의 특성**, **일반화가 필요한 범위**에 따라 달라집니다.

| 방식 | 핵심 전제 | 주요 강점 |
|---|---|---|
| **단일 모델 학습** | 충분한 레이블 데이터 확보 가능 | 구현 단순, 태스크 특화 성능 |
| **Transfer Learning** | 소규모 타깃 데이터에서 빠른 적응 필요 | 레이블 효율, 피험자 개인화 |
| **Foundation Model** | 레이블 없이 범용 표현 학습 | 다태스크 확장성, 대규모 사전학습 |
