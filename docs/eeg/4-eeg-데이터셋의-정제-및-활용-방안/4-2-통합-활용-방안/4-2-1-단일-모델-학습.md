# 4.2.1 단일 모델 학습 (Unified/Joint Training)

## 개념

여러 출처에서 수집된 EEG 데이터셋을 하나의 통합 학습 데이터로 구성하고, 단일 모델을 처음부터(from scratch) 학습하는 방식입니다. 데이터 이질성(heterogeneity)을 전처리 단계에서 최대한 해소한 뒤, 모델이 다양한 분포에서 공통 특징을 학습하도록 유도합니다.

## 이 방식을 선택하는 상황

- **레이블이 충분할 때**: 통합된 데이터셋에 레이블이 풍부하게 있어 처음부터 지도학습이 가능한 경우
- **동일 태스크 데이터를 여러 데이터셋에서 확보했을 때**: 예를 들어 Motor Imagery 데이터셋 3개를 통합하여 단일 분류기 학습
- **도메인 다양성으로 일반화를 높이고 싶을 때**: 다양한 피험자·장비·환경에서 수집된 데이터로 학습하면 단일 데이터셋 모델보다 일반화 성능이 향상될 가능성이 있습니다

## 핵심 전처리 요건

단일 모델 학습이 성공하려면 입력 형태가 완전히 통일되어야 합니다. 4.1절에서 다룬 전처리가 필수적으로 선행되어야 합니다.

- **샘플링 주파수 통일**: 모든 데이터셋을 동일한 Hz로 리샘플링
- **채널 정렬**: 공통 채널 추출 또는 채널 보간으로 입력 채널 수 통일
- **신호 길이 통일**: 동일한 윈도우 크기로 에포킹
- **정규화**: 데이터셋 간 진폭 스케일 차이를 피험자별 Z-score로 보정

## 고려사항 및 한계

**도메인 편향(Domain Shift)**: 서로 다른 장비, 수집 환경, 피험자 그룹에서 온 데이터는 분포가 다릅니다. 단순히 합쳐서 학습하면 대규모 데이터셋이 소규모 데이터셋의 신호를 압도하여 편향이 발생할 수 있습니다. 데이터셋별로 균형 샘플링(balanced sampling)이나 가중치 조정이 필요합니다.

**레이블 불일치**: 같은 "Emotion Recognition" 태스크라도 데이터셋마다 감정 카테고리 정의가 다를 수 있습니다. DEAP는 Valence-Arousal 2차원 연속값, SEED는 3분류(긍정/중립/부정) 레이블을 사용합니다. 이 경우 레이블 공간을 통일하거나, 태스크별로 별도 출력 헤드를 두는 멀티태스크 학습 구조가 필요합니다.

**적합하지 않은 상황**: 각 데이터셋이 매우 다른 태스크나 뇌 상태를 대상으로 할 때, 또는 레이블이 부족하거나 없을 때는 Transfer Learning 또는 Foundation Model 방식이 더 적합합니다.
