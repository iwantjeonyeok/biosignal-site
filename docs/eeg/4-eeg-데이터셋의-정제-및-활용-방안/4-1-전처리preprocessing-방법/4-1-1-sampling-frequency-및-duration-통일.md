# 4.1.1 Sampling Frequency 및 Duration 통일

## 왜 필요한가

공개 EEG 데이터셋들은 수집 목적, 사용 장비, 기록 기간에 따라 샘플링 주파수와 기록 길이가 서로 다릅니다. 예를 들어 DEAP는 128 Hz, PhysioNet Motor Imagery는 160 Hz, TUEG 계열은 250~1000 Hz로 다양합니다. 이 상태 그대로 여러 데이터셋을 하나의 모델에 입력하면, 같은 1초 동안의 신호가 어떤 데이터셋에서는 128개 샘플, 다른 데이터셋에서는 1000개 샘플이 되어 모델이 정보를 일관되게 처리할 수 없습니다. 기록 길이도 마찬가지로, 짧은 trial과 긴 연속 기록을 동일한 입력 형태로 맞추는 과정이 필요합니다.

## 주요 방법

### Resampling (리샘플링)

서로 다른 샘플링 주파수를 하나의 목표 주파수로 통일하는 과정입니다.

- **다운샘플링(Downsampling)**: 높은 주파수 → 낮은 주파수로 변환. 예: 1000 Hz → 250 Hz. 반드시 다운샘플링 전에 **앤티앨리어싱 저역통과 필터(anti-aliasing low-pass filter)**를 적용해야 합니다. 그렇지 않으면 목표 주파수의 나이퀴스트 한계를 초과하는 성분이 저주파 대역으로 접혀 들어오는 앨리어싱(aliasing) 왜곡이 발생합니다.
- **업샘플링(Upsampling)**: 낮은 주파수 → 높은 주파수로 변환. 실제 측정하지 않은 샘플을 보간(interpolation)하여 채우는 것이므로, 새로운 정보가 생성되는 것이 아님을 주의해야 합니다. 신호-잡음비(SNR) 개선 없이 데이터 크기만 늘어납니다.
- **목표 주파수 선택 기준**: 분석하려는 가장 높은 주파수 성분의 최소 2배를 유지해야 합니다(나이퀴스트 정리). 예를 들어 Gamma(30 Hz)까지 분석할 경우 최소 64 Hz 이상이 필요하며, 실무에서는 여유를 두어 128 Hz 이상을 사용합니다.

### Windowing (윈도잉)

연속적인 EEG 기록을 고정된 길이의 세그먼트(epoch)로 분할하는 과정입니다.

- **윈도우 크기(Window Size)**: 태스크 특성에 따라 결정합니다. ERP 분석처럼 자극 후 짧은 시간 안에 반응이 나타나는 경우는 0.5~2초, 수면 단계 분류는 AASM 기준에 따라 30초 윈도우를 사용합니다.
- **슬라이딩 윈도우(Sliding Window)**: 윈도우를 일정 간격(stride)으로 이동시키며 연속적으로 세그먼트를 생성합니다. 오버랩(overlap)을 주면 데이터를 증강하는 효과가 있지만, 학습셋/테스트셋 분리 시 시간적으로 인접한 세그먼트가 양쪽에 포함되지 않도록 주의해야 합니다(데이터 누수 위험).
- **에포킹(Epoching)**: 자극 제시 시점(event marker)을 기준으로 전후 일정 시간을 잘라내는 방식. ERP 연구의 표준 방법입니다.

### Zero Padding

일부 짧은 신호를 긴 신호와 동일한 길이로 맞추기 위해 끝부분에 0을 채우는 방법입니다. 주파수 분석(FFT)의 주파수 해상도를 높이기 위한 목적으로도 사용됩니다. 단, 패딩된 0이 모델 학습에 의미 없는 패턴으로 학습될 수 있으므로, 마스킹(masking) 처리 또는 어텐션 메커니즘이 있는 모델에서 패딩 위치를 무시하도록 설정하는 것이 바람직합니다.

## 실무 주의사항

- 다운샘플링 전 anti-aliasing 필터 적용은 필수입니다.
- 슬라이딩 윈도우로 생성한 세그먼트를 학습/검증/테스트로 분할할 때는 **피험자 단위(subject-wise split)** 또는 **시간 단위(temporal split)**로 나누어야 데이터 누수를 방지할 수 있습니다.
- 목표 샘플링 주파수는 분석 대상 태스크의 주요 주파수 성분과 모델 입력 크기의 trade-off를 고려하여 결정합니다.
