# 4.2.2 Transfer Learning (전이 학습)

## 개념

전이 학습이란 대규모 소스 데이터셋에서 사전학습(pre-training)된 모델의 가중치를 초기값으로 활용하고, 상대적으로 소규모인 타깃 데이터셋에서 미세조정(fine-tuning)하는 방식입니다. EEG는 수집 비용이 높고 레이블링이 어려워 개별 태스크에서 대규모 데이터를 확보하기 어렵기 때문에, 전이 학습이 특히 중요한 전략입니다.

## EEG에서 전이 학습이 필요한 이유

EEG 데이터는 다음과 같은 이유로 소규모 데이터 문제를 구조적으로 가지고 있습니다.

- **수집 비용**: 피험자 모집, 장비 세팅, 실험 진행에 상당한 시간과 비용이 요구됩니다
- **레이블링 어려움**: 수면 단계, 발작 구간 등은 전문 임상의가 직접 레이블링해야 합니다
- **개인 특이성**: 동일 태스크라도 피험자마다 신호 패턴이 달라, 타깃 피험자 데이터를 충분히 수집해야 성능이 확보됩니다

## 전이 학습의 유형

### 피험자 간 전이 (Cross-Subject Transfer)

여러 피험자로부터 학습된 모델을 새로운 피험자에게 적용합니다. 가장 흔한 형태의 EEG 전이 학습으로, "피험자 독립(subject-independent)" 또는 "피험자 일반화(subject generalization)" 문제라고도 합니다. 모델이 피험자 특이적 패턴보다 태스크에 공통된 뇌 패턴을 학습하도록 유도하는 것이 핵심입니다.

### 태스크 간 전이 (Cross-Task Transfer)

A 태스크(예: Sleep Stage)에서 사전학습된 모델을 B 태스크(예: Seizure Detection)에 적용합니다. 저수준 EEG 특징(주파수 구조, 공간 패턴)은 태스크와 무관하게 공유되므로, 사전학습 모델의 초기 레이어가 유용한 표현을 이미 학습하고 있다는 가정에 기반합니다.

### 도메인 적응 (Domain Adaptation)

소스 도메인(특정 데이터셋, 피험자 그룹, 장비)과 타깃 도메인 간의 분포 차이(domain shift)를 줄이는 방법입니다. 단순 fine-tuning 외에도 Adversarial training, Maximum Mean Discrepancy(MMD) 최소화 등 분포 정렬 기법을 사용합니다.

## Fine-tuning 전략

| 전략 | 방법 | 적합한 상황 |
|---|---|---|
| **Full fine-tuning** | 전체 레이어 재학습 | 타깃 데이터가 상대적으로 충분할 때 |
| **Last-layer fine-tuning** | 출력 레이어만 재학습 | 타깃 데이터가 매우 적을 때 (과최적화 방지) |
| **Partial fine-tuning** | 일부 상위 레이어만 재학습 | 소스-타깃 도메인이 부분적으로 다를 때 |
| **Adapter tuning** | 경량 어댑터 모듈만 학습 | 원본 모델 가중치를 유지하면서 다중 태스크 적응 |

## 실무 고려사항

- **레이어 동결(Layer Freezing)**: 사전학습 모델의 초기 레이어(저수준 특징 추출)는 동결하고, 상위 레이어만 fine-tuning하는 것이 데이터가 적을 때 효과적입니다.
- **학습률(Learning Rate)**: Fine-tuning 시에는 사전학습된 가중치를 크게 변경하지 않도록 작은 학습률(예: 1e-4 ~ 1e-5)을 사용합니다.
- **데이터 누수(Data Leakage) 방지**: 소스 데이터에 타깃 피험자의 데이터가 포함되지 않아야 합니다. 특히 여러 데이터셋을 통합할 때 동일 피험자가 여러 데이터셋에 있는지 확인이 필요합니다.
