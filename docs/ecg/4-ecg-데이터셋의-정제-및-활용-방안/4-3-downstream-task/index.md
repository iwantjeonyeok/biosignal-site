# 4.3. Downstream Task

ECG downstream task는 ECG foundation model이 사전학습 이후 실제로 어떤 문제에 활용되는지를 보여줍니다. 최근 연구에서는 단순 부정맥 검출을 넘어, ECG 진단 label 분류, 심장 기능 예측, 임상 사건 예측, 생체 정보 추정, 그리고 불완전한 ECG 환경에서의 robustness 평가까지 다양한 task가 수행되고 있습니다.
